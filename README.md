# Aula 01 — FAID

## Ambiente

Python 3.14 e ambiente virtual venv.

## Como configurar

1. Criar o ambiente:

python -m venv .venv

2. Ativar no Windows:

.venv\Scripts\Activate

3. Instalar as dependências:

python -m pip install -r requirements.txt

4. Abrir o notebook:

notebooks/notebook_EDA.ipynb

## Dataset

Gait in Parkinson's Disease v1.0.0  
Fonte: PhysioNet  
DOI: https://doi.org/10.13026/C24H3N
